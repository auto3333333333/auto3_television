# rensyu_television

[English](README.md)

FiveM 用のテレビ & ブームボックスです。すべての状態が全プレイヤーに同期されます。

- テレビで **YouTube / Twitch** の動画・ライブ配信を視聴（距離で音量が変わり、途中から見た人も同じ位置から再生）
- YouTube / Twitch をサーバー全体の **チャンネル** として配信（固定チャンネル・共有チャンネル・プレイヤーが開設するチャンネル）
- Webサイトを表示し、マウスで **操作**
- 画像 / 動画 / 音声ファイルの直リンク表示
- **ブームボックス**: `ox_inventory` のアイテムで小道具を設置し、音を流せる
- タブレット風UI、多言語対応（日本語・英語を同梱）

## 必要なリソース
| リソース | |
|---|---|
| `ox_lib` | 必須 |
| `ox_target` | 任意（無い場合は TextUI + キー操作） |
| `ox_inventory` | ブームボックスを使う場合のみ |

## 導入
1. `rensyu_television` を `resources` に置く
2. `server.cfg`
   ```
   setr ox:locale ja            # 英語は en
   ensure ox_lib
   ensure ox_target             # 任意
   ensure rensyu_television
   add_ace group.admin rensyu_television.broadcast allow   # チャンネルへ配信できる人
   ```
3. 元の `generic_texture_renderer_gfx` リソースを使っていた場合は **削除** してください（同じファイルを `stream/` に同梱しています）
4. ブームボックス: `install/ox_inventory_items.lua` の内容を ox_inventory の `data/items.lua` に追加

## 言語
言語は `ox:locale` コンバーに従います。日本語(`ja`)と英語(`en`)を同梱しています。
言語を追加するには、`locales/en.json` を `locales/<コード>.json` にコピーして値を翻訳してください。

## 対応するリンク
YouTube: `watch?v=`、`youtu.be/`、`shorts/`、`live/`、`embed/`、プレイリスト、`channel/UC...`（ライブ）、`?t=90` の開始位置。
Twitch: チャンネル、`popout/` / `embed/` のリンク、VOD（`/videos/123`、`?t=1h2m3s`）、クリップ（`clips.twitch.tv/`、`.../clip/`）、`player.twitch.tv/?channel=`。
それ以外は、Webページ・画像・動画・音声のリンクとして扱います。

## 使い方
- **テレビ**: ox_target の「テレビを操作する」、または `/tv`。ox_target が無い場合は案内が出て、ox_lib のキーバインド（初期値 `E`、FiveM のキー設定で変更可）で開きます
- タブレット画面の左サイドバー: *リモコン* / *チャンネル* / *プリセット* / *履歴*
  - リモコン: 再生状況、一時停止・シーク・最初から・同期し直し、種類選択、URL、音量、「画面を操作」、電源OFF
  - チャンネル: テレビに映す / 配信（権限がある場合）
  - 履歴: ページ・動画の **題名** を表示（サーバーが取得してキャッシュ）
- **画面を操作**: 周りにゲーム画面が見える窓で、最前列に表示します。マウスでクリック・スクロール。**×** ボタンまたは `Esc` で閉じます
- `/broadcast`: テレビの近くにいなくても放送管理を開けます
- `/tvmodel`: 近くのオブジェクトのモデルハッシュを表示（未対応のテレビを追加するときに使用）

### チャンネル
- `Config.Channels` で `url` を書いたチャンネルは **固定**（誰も上書きできません）
- `url` の無いチャンネルは共有チャンネル（配信権限がある人が使えます）
- 権限のある人は **自分のチャンネル** を開設できます（CH 01, 02 ... の番号。退出すると閉じます）
- テレビには `CH 01` の表示が出て、放送の開始・終了が通知されます

### ブームボックス
1. アイテム `boombox` を使うと目の前に小道具を設置（アイテムを消費）
2. 小道具をターゲットして操作パネルを開く: YouTube / Twitch / 音声ファイルの **音だけ** を再生。一時停止・シーク・最初から・停止・音量
3. 「拾う」でアイテムが戻ります（誰が拾えるかは `Config.Boombox.PickupAnyone`）
- 距離で音量が下がり、壁でこもり、密閉された部屋からは完全に無音になります（`Config.Occlusion`）
- 同時に鳴るのは近い順に `Config.Boombox.MaxActive` 台まで
- ブームボックスの操作パネルを開いている間は、キャラクターがアニメーションを再生します（`Config.Boombox.Animation`、`false` で無効）

## 設定
すべて `config.lua`（コメント付き）です。距離、音量、権限(ACE)、承認フック、禁止ワード、チャンネル、プリセット、
テレビのモデル、設置するテレビ、ブームボックス、YouTube の言語、ページ題名の取得など。

## セキュリティに関する注意
- 入力はサーバー側で検証し、連打も制限しています。`http(s)` のURLのみ受け付けます。独自のルールは `Config.BannedWords` / `Config.BlockedHosts` / `Config.Hooks` で追加できます
- **ページの題名**: サーバーがURLにアクセスして `<title>` を読みます（YouTube は oEmbed、メディアファイルはファイル名）。
  localhost や社内アドレスへのアクセスは拒否しますが、「名前解決すると社内アドレスになるホスト名」は検出できません。
  気になる場合は `Config.Titles.FetchWeb = false`（または `Enabled = false`）にしてください

## 制限事項
- GTA V の仕様で、同じ画面名（`tvscreen` など）のテレビは画面を共有し、最後に操作した/一番近い1台だけが描画されます。
  1台ずつ別の映像にするには、モデルを変えるか、`Config.TVModels` の3D描画モード（`Target = nil` + `Offset` / `Scale`）を使ってください
- Web の操作はマウスのみ（FiveM の DUI はキーボード入力を受けられません）。クリックは操作した本人の画面にだけ反映されます
- 一時停止・シークは、動画・YouTube動画・Twitch VOD・音声ファイルのみ（ライブ配信・Web・画像は対象外）
- 非公式な機能（YouTube の音声トラック選択、推測で入れたテレビモデル）は、動かない場合があります
- 所有者が **埋め込みを無効にしている動画**（YouTube のエラー101/150）と Twitch のクリップは、通常のYouTube / Twitchのページを開いて再生します。再生はできますが、距離による音量調整と一時停止・シークの同期は効きません（「画面を操作」でページをクリックできます）
- HLS(.m3u8) など、ブラウザが直接再生できない形式は非対応です
- ブームボックスはサーバー再起動で消えます（リソース停止時はオンラインの持ち主にアイテムを返します）
